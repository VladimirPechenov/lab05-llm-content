# ЛР №5 — Печенов В. В., ИВТ-465

Полная работа по опубликованному шаблону преподавателя.

- 3 генератора с реальной локальной Qwen2.5 7B, JSON/Pydantic и ограниченной коррекцией.
- 10 квестов, 20 предметов, 3 NPC с отдельной историей.
- С первой попытки: квесты 10/10, предметы 19/20, диалоги 8/9; после повторов весь корпус готов.
  В диалогах учтён один HTTP 500 Ollama, после которого прогон продолжен с контрольной точки.
- Streamlit-просмотр без модели и отдельный режим живой генерации.
- Сохранены реальные ответы, естественный дубль, отрицательные опыты и проверки роли до/после исправлений.
- PDF на 8 страниц, Markdown, видеопротокол 3:00 с поясняющими надписями без звука.
- 11 тестов, линтер, аудит и GitHub Actions без платных ключей.
