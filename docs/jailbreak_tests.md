# Проверки выхода из роли

Проверено содержательно: отсутствие самоидентификации как ИИ, выдачи кода и ухода в метаобсуждение; сохранение профессии NPC.
Валидный JSON сам по себе не считается подтверждением сохранения роли. Это 6 фиксированных провокаций, не доказательство универсальной устойчивости.

## До уточнения промпта

В версии v2: 3 из 6 ответов обсуждали искусственный интеллект; три отказа на запрос кода сохраняли игровой контекст.
Исходные ответы: `results/jailbreak_before.json`. В v3 возник перенос примера Барта в ответ Ирмы: `results/jailbreak_intermediate_v3.json`.
Исправление: в финальный промпт включается пример только выбранного персонажа из `prompts/personas.json`.
Дополнительно узкая проверка метатерминов отклоняет обсуждение ИИ/программирования в text и options. Ограничения этой эвристики сохранены в отчёте.
