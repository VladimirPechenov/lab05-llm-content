# Источник требований

https://github.com/kolesnikov-vstu-gameai/lab05-llm-content

- Три генератора: квест, предмет, реплика NPC; JSON и Pydantic, повтор при ошибке.
- Корпус 10 квестов + 20 предметов, диалоговая система с 3+ NPC.
- Streamlit-демо или ноутбук.
- Таблица качества: первые попытки / после повторов / уникальные названия.
- 2–3 неудачных ответа модели и разбор, изменения промптов отдельными коммитами.
- Проверки выхода NPC из роли (docs/jailbreak_tests.md).
- По шаблону docs/report.md: отчёт 6–8 страниц, Markdown и PDF.
- Коммиты step-1 и далее, видео YouTube/Диск без MP4 в Git, тег v1.0 и Release.

Как и для ЛР4, отдельные методические указания и официальный шаблон кафедры
отсутствуют; отчёт оформляется как учебный протокол. ФИО: Печенов В. В., ИВТ-465.
Реальные вызовы модели и управляемые отрицательные эксперименты помечаются раздельно.
