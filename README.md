## Фактические результаты

Корпус создан **локальной qwen2.5:7b через Ollama**, не шаблонными заглушками.
В таблицу входят только задачи основного корпуса и обычных диалогов. Отрицательные эксперименты
и провокации NPC учтены отдельно.

| Генератор | Задач | Вызовов модели | Валиден с 1-й попытки | После повторов | Уникальных названий |
|---|---:|---:|---:|---:|---:|
| quest | 10 | 10 | 10/10 | 10/10 | 10 |
| item | 20 | 21 | 19/20 | 20/20 | 20 |
| dialogue | 9 | 10 | 8/9 | 9/9 | — |

В диалогах один запрос завершился HTTP 500 Ollama. Он включён в число вызовов и уменьшает
первую успешность до 8/9; после продолжения с контрольной точки получены все 9 ответов.
Ошибка транспорта записана отдельно в `results/transport_incidents.json`.

Исходные ответы, ошибки, seed, время, токены и хеш промпта: [generation_trace.json](results/generation_trace.json).
Независимо пересчитываемые метрики и SHA-256 корпуса: [metrics.json](results/metrics.json).
Версии ПО, Ollama и digest модели: [environment.json](results/environment.json).
Лексическая уникальность названий не доказывает сюжетное разнообразие и игровой баланс.

**Три отрицательных опыта с настоящей моделью:**

1. Снижение бюджета до 40 токенов: JSON обрывается. В основном прогоне бюджет 900.
2. Слабый промпт прямо просит Markdown: полный строгий парсер отклоняет обёртку.
3. Модель просят повторить уже принятый JSON: совпадает название, проверка новизны отклоняет дубль.

Это **контролируемые условия**, они не выдаются за естественную частоту ошибок основного корпуса.
Полные исходные ответы и условия: [baseline_failures.json](results/baseline_failures.json).
Финальные промпты запрещают обёртки, закрепляют допустимые поля и требуют учитывать занятые названия;
JSON mode и Pydantic работают независимо. Бюджет токенов исправлен как параметр генерации.

## Запуск демонстрации

Python **3.12+**. Windows: **RUN.cmd**; проверка: **CHECK.cmd**.
Готовый корпус можно смотреть без Ollama, ключей API и новых вызовов модели.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py --browser.gatherUsageStats false
```

На Linux/macOS: `python3 -m venv .venv`, затем `.venv/bin/python` вместо Windows-пути.
Четыре вкладки: квесты, предметы, диалоги, качество. В боковом меню режим **«Готовый корпус»**
показывает сохранённые настоящие ответы; **«Живая LLM»** создаёт новые.

Персонажи: **Торговец Барт**, **Стражница Ирма**, **Старик Йор**.
В живом режиме истории разделены по персонажам; модель получает последние 6 реплик.
Смена NPC не переносит чужой контекст. Проверяются точное имя, эмоция, 2–4 варианта ответа,
лимит в 60 слов. [Проверки выхода из роли](docs/jailbreak_tests.md) требуют содержательной оценки,
а не одного успешного разбора JSON.

На фиксированном наборе провокаций: до уточнений роли сохранили 3/6 ответов, в финальной
конфигурации — 6/6. Сравнивались промпт, изоляция примеров и узкая проверка метатерминов вместе.
Промежуточные ошибки сохранены. Редакторские замечания к корпусу: [editorial_review.md](docs/editorial_review.md).

## Реальная генерация и повтор эксперимента

Установите [Ollama](https://ollama.com/download) и загрузите модель:

```bash
ollama pull qwen2.5:7b
ollama serve
```

Если Ollama уже работает, второй экземпляр сервера не нужен. Скопируйте `.env.example` в `.env`:

```dotenv
LLM_PROVIDER=ollama
LLM_MODEL=qwen2.5:7b
OLLAMA_URL=http://127.0.0.1:11434
```

```bash
python -m lab05.generators --quests 10 --items 20
python -m lab05.audit
```

Пакетный прогон сохраняет результат после каждого объекта и продолжает незавершённый корпус.
Чтобы выполнить **новый** независимый эксперимент, сначала переместите прежние `data/out/` и
`results/` в архивную папку. Существующий корпус не выдаётся за свежую генерацию.
Точное совпадение байтов ответов на другом GPU/версии Ollama не гарантируется; сохранённые
ответы и хеши позволяют воспроизвести проверку уже выполненного прогона.

Адаптеры OpenAI/Anthropic доступны через `LLM_PROVIDER`, `LLM_MODEL` и соответствующий ключ
в `.env`; основной эксперимент и проверка выполнены через **Ollama**. Облачные адаптеры в данном
прогоне не вызывались. Секреты и веса модели в Git не включены.

## Проверки и структура

```bash
python -m ruff check .
python -m pytest
python -m lab05.audit
```

Тесты проверяют коррекцию и предел повторов, повторы названий, ограничения схем, имя NPC,
ограничение контекста, ошибки транспорта, параметры Ollama, весь корпус и Streamlit-просмотр.
Тестовые ответы явно помечены `provider=test`; в фактическом корпусе их нет.
CI не требует ключей или загрузки весов модели.

| Путь | Содержимое |
|---|---|
| `src/lab05/` | Клиент, схемы, генераторы, пакетный прогон и аудит |
| `prompts/` | Версионируемые системные промпты и описание персон |
| `data/out/` | 10 квестов, 20 предметов и 9 обычных ответов трёх NPC |
| `results/` | Реальные исходные ответы, метрики, окружение и провокации |
| `app/streamlit_app.py` | Просмотр сохранённого корпуса и живая генерация |
| `docs/report.pdf` | Отчёт на 8 страниц |
| `docs/jailbreak_tests.md` | Ручная проверка выхода из роли |
| `tools/` | Отрицательные опыты, воспроизводимое оформление отчёта и видео |
| `videos/chapters.json` | Таймкоды; MP4 хранится на Диске/в Release |

Для повторного оформления: `pip install -e ".[artifacts]"`, затем
`python tools/build_report.py`, `python tools/build_video.py`.
Нужны Arial (Windows) или DejaVu (Linux). Промпты и результаты связаны хешами в журнале.

Ограничения: небольшой корпус и одна модель; нет формальной проверки лора и экономики,
долговременной памяти и доказательства устойчивости к любым провокациям. Генерация создаёт
черновики; перед включением в игру нужен редакторский просмотр и игровые тесты.
